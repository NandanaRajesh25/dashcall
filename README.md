## 📖 Description
ApexVelocity is a physics-based road and track annotation engine designed for autonomous vehicle (AV) teams and researchers. With a core built in C++20 and user-friendly frontends in Python and Go, this application helps streamline the process of annotating roads and tracks for AVs and robotaxis.

## 📦 Features
- Efficient road and track annotation
- Supports complex scenarios for accurate planning
- Cross-platform with intuitive Python and Go interfaces
- Ideal for research and development in autonomous driving
- Integration with OpenStreetMap for better data representation
- Reinforcement learning algorithms for improved system performance
